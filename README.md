# DriveX

Abra **DriveX.sln** no Visual Studio. O arquivo `.sln` é a opção mais compatível.

Antes de executar, troque `SUA_SENHA` no arquivo `appsettings.json` pela senha do MySQL e crie a tabela `veiculos` com as colunas `id_vei`, `modelo_vei`, `marca_vei`, `placa_vei`, `ano_vei`, `categoria_vei` e `status_vei`.
