# AutoFrota

Projeto simples de gerenciamento de automóveis feito em ASP.NET Core Blazor.

## Abrir no Visual Studio

1. Abra `AutoFrota.slnx` no Visual Studio 2026 (ou `AutoFrota.sln` em versões anteriores).
2. Pressione `F5` ou use o perfil **http**.
3. Para versionar, abra a pasta `AutoFrota` no GitHub Desktop e crie o repositório.

O projeto usa dados em memória, por isso não precisa configurar banco de dados para a demonstração.
